## Почему именно такое доменное деление
#### Автономия бизнесов
Клиники, банк и фарма - это разные бизнесы, которые не должны зависеть друг от друга.
Поэтому при добавлении данных в одном месте, не должна страдать другая часть бизнесов

#### Выделение домена AI 
Поскольку для работы ИИ требуется специальным образом подготовленные данные, то необходимо выделение этого в отдельный домен, а также завести feature store. Логично, чтобы команда DS занималась всеми вопросами для ИИ без вмешательства в другие домены и без использования общей очереди в изменение скриптов SQL командой

#### Выделение домена Data Platform
отдельная команда будет заниматься обслуживанием внутренней платформы, которая включает Data Lake, Data Hub и тд, что позволит заниматься улучшением платформы, а не решением запросов по переписыванию скриптов конкретных пользователей данных, что увеличит пользу от данной команды для всех пользователей данных

#### Выделение домена Corporate Ops
Вся административная часть бизнеса - hr, финансовый департамент, включая бухгалтерию и тд должны иметь доступ к специфичной информации, которая в большей степени направлена на учет операций и формирование отчетности, что не пересекается с остальными типами операций

#### Time-to-market
Разделение поможет избежать центральной очереди на изменение SQL скриптов, тк Data Hub будет подписан на изменения данных и витрины данных сами будут изменяться вслед за изменением данных

#### Безопасность by design
Поскольку разные домены требуют разного отношения к безопасности данных, то и разделять нужно по сферам. Например для медицинских данных - одни правила шифрования и доступов, для финансовых данных также будет свои ограничения связанные с банковской тайной. Эти данные содержат PII/PHI и не могут быть доступны другим пользователям

#### Легкая расширяемость на другие бизнесы
Выделение доменов на основе бизнесов должно способствовать легкому подключению новых бизнесов в будущем
